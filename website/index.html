    What's in the jar

    Upgrades, abilities, chests and loot bags in one plugin. Every cost, effect and drop chance lives in a YAML file you can edit and reload.

    UpgradeTree 2.4

    • Hexagon panel

      A 3D panel opens in front of the player and only they see it. Each frame shows whether an upgrade can be bought, is owned or is finished.

    • Progressive reveal

      An upgrade appears once something it needs is bought, so the tree grows out of the Origin as players progress.

    • Four styles

      NIGHT, CELESTIAL, MINIMAL and WOOD colour the panel, the chest menus and the chat messages together.

    • Free movement

      The panel stays where it opened. Players walk around it, look away to play, and walk off to close it.

    • Sixteen effect types

      Attributes, potions, XP boost, double drops, crits, lifesteal, dodge, auto smelt, vein miner, tree feller, keep XP or items, and console commands.

    • Active abilities

      Dash, Leap, Heal, Shield, Speed Burst and Shockwave on Sneak + F, a double sneak or Sneak + Jump.

    • Chests

      CS2-style cases bought with the tree's currency. The prize strip spins over the chest itself, right where the player stands.

    • Loot bags

      Seven rarities from Common to Secret drop from player kills. Rare finds glow on the ground and are announced to the server.

    • Prestige and respec

      A finished tree can be prestiged for permanent bonuses, up to prestige 10. A reset refunds 75% of what was spent.

    • Three currencies

      XP levels, Vault money, or the plugin's own points from kills, playtime, ores, advancements and a daily reward.

    • Leaderboard

      /tigo top ranks players by prestige or by levels, and a floating hologram shows the top ten in the world.

    • Bedrock players

      Geyser and Floodgate players get a chest menu automatically. Anyone can switch with /tigo menu.

    • Admin panel

      Operators edit points, prestige and every upgrade level in /tigo admin, or change a player's tree right on the hexagon panel.

    • Storage

      YAML, SQLite or MySQL with batched saves. Old YAML data moves into a new, empty database by itself.

    • PlaceholderAPI

      Placeholders for scoreboards, tab lists and holograms, from the balance to the state of a single upgrade.

    • Safe updates

      /tigo update installs the newest release. Player data, the old jar and every plugin file are backed up first.

      Commands

      Everything runs under /tigo. Players have upgradetree.use by default, operators get upgradetree.admin.

      Players upgradetree.use

      • /tigoOpens or closes the panel
      • /chestOpens the Chests section (also /chests)
      • /tigo info [player]Shows the upgrades and the command list
      • /tigo respec [confirm]Resets your tree with a 75% refund
      • /tigo prestige [confirm]Prestiges a finished tree
      • /tigo top [prestige|levels]Leaderboard
      • /tigo menu <panel|chest|auto>Picks the 3D panel or the chest menu
      • /tigo dailyDaily reward (POINTS currency)

      Admins upgradetree.admin

      • /tigo admin [player]Admin panel: points, prestige, levels, settings
      • /tigo reload · /tigo checkReloads the files · finds cycles, unreachable upgrades and overlapping hexagons
      • /tigo set <player> <upgrade> <level>Sets one upgrade's level
      • /tigo points <give|take|set> <player> <amount>Changes points
      • /tigo reset <player> · /tigo prestige set <player> <level>Resets a player · sets a prestige level
      • /tigo chests give <player> <chest> [amount]Gives unopened chests, offline players too
      • /tigo lootbag give <player> <rarity> [amount]Gives loot bag items
      • /tigo npc · /tigo top place|removeTags the entity you look at · places the hologram
      • /tigo update [restart]Installs the newest release with a backup
      • /tigo cleanup <player|all>Removes the plugin's bonuses before uninstalling

      Set it up

      1. Run Paper 26.3 on Java 25

        Purpur and Leaf work too. Vault, PlaceholderAPI, Geyser and Floodgate are optional and picked up by themselves.

      2. Drop the jar into plugins

        Put UpgradeTree-2.4.0.jar in the plugins folder and restart. Later versions install with /tigo update.

      3. Edit, reload, check

        Change config.yml or a tree, run /tigo reload, then /tigo check to catch mistakes in the trees.

      The plugin folder

      • plugins/UpgradeTree/

      Updating from 2.2 or older

      Everything converts on the first start. Old upgrade and chest ids move to the new ones, edited files are kept, and config.yml gets the new settings with every value kept.

      Before removing the plugin, run /tigo cleanup all so the health and damage bonuses leave the players.
